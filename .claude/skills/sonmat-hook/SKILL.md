# sonmat-hook — 2. 훅

엔진별로 이미 있는 훅·이벤트 줄 형식·함수 찾는 법은 `engines.md` 의 훅 표를 본다. 새 엔진이면 새 레포 `sonmat-hook-<이름>`(CI 빌드, 태그 `v*` = 릴리스 zip) → `sonmat-games/parts.json` 에 한 줄(주소·sha256·files) → `hook.json` 의 `native.dll`. 앱 메인에 DLL 소스를 넣지 않는다.

## 함수 찾기
- 먼저 `engines.md` 의 도구(`find_ue4_audio.py`, `find_ak.py`·`find_ak_mem.py` 등). 안 되거나 새 엔진이면 rea(스킬 `reverse-engineer-anything`)로: 소리 이름을 쓰는 문자열의 호출처, 이름→번호 계산 뒤에 부르는 함수, 네이티브 함수 표, 내보낸 공개 함수.
- **인자 형식을 확인하기 전에는 걸지 않는다.** 게임을 한 번 죽이면 신뢰를 잃는다. 가장 많이 불리는 후보가 답이 아니다(니어 첫 후보는 실수값을 받는 RTPC 설정).
- 포장된 실행 파일(엔트로피 8.0)은 켜진 게임의 메모리에서만 찾는다. 읽어 온 코드 사본은 끝나면 지운다. 포장을 벗기는 도구는 쓰지 않는다.
- 훅 주소·패턴 같은 분석 결과는 게임 레포의 `hook.json` 에 둔다(바이트 패턴 파일도 게임 레포, `native.sigs_file`). 게임 폴더에만 있는 손 파일을 만들지 않는다(10-17 재설치 때 사라져 오공이 튕겼다).

## 무엇을 받나
- **훅은 소리가 지나가는 길에만 건다.** 무엇을 장착했나 같은 게임 상태를 알자고 다른 함수를 걸거나 메모리를 읽지 않는다. 쓸 때 나는 소리로 상태를 기억하는 것(프로필 `state`)까지만.
- **소리 끝도 받는다.** 컷씬처럼 "그 소리가 나는 동안"만 유효한 것은 시작만으로는 끝을 모른다. 소리 시작 함수와 함께 소리 종료도 찾는다(엔진별 현황은 `engines.md`).
- **주인을 받는다**: 소유자 이름(언리얼 액터) → 게임 오브젝트 번호(내 발소리를 내는 오브젝트가 나, Wwise·유니티) → 이름 접두(`pl`/`em`) → 소리 위치와 듣는 위치의 거리 → MAME 은 버튼을 누른 패드. 이름에 주인이 없는 게임은 이게 품질을 정한다(없으면 적의 발소리·칼질까지 내 것으로 울린다).
- **바닥이 발소리와 따로 오는 엔진**(Wwise 스위치·RTPC)은 스위치 훅(`wsw:`·`wrt:`)이 있어야 바닥별 발소리가 된다. 니어는 발걸음마다 오브젝트 번호가 새로 생기고 바닥 RTPC 와 같은 번호로 짝지어 온다.

## 붙이기
1. **게임 없이 먼저 시험한다**: 그 소리 DLL 을 시험 프로세스에 무음 출력으로 띄우고 훅을 붙여 호출이 통과하고 기록이 남는지 본다. 시험 통과는 "튕기지 않는다"까지만 말한다 — 게임이 같은 방식으로 부르는지는 켜 봐야 안다(세키로: 시험에선 이름이 나왔는데 게임은 묶음을 이름 없이 올려 전부 `(null)`).
2. **처음 붙일 때는 타이틀 화면에서**, 저장 안 된 진행이 없는지 확인하고. 세이브가 없는 구간으로 시작하는 게임은 "튕기면 처음부터"라고 미리 알린다. 게임을 켜 달라고 부탁하는 것은 여기 한 번이다(수집 플레이를 시키는 게 아니다).
3. 첫 실행 뒤 가장 먼저 볼 것은 훅 상태 파일이 아니라 **이벤트 파일의 내용**: 줄이 오는가, 이름이 읽히는가, 1단계 이름표와 맞는가. 타이틀·메뉴에서 나는 소리만으로도 형식은 확인된다.
4. 게임 안에서 한 번도 안 돌린 훅은 사용자에게 **"손맛 켜고 이 게임을 해 본 적이 없다"**고 말한다.

## 붙은 뒤 기록으로 알 수 있는 것 (이미 쌓인 기록이 있을 때)
- **이름표에 없는 번호가 많이 오면 핵심 소리일 수 있다**(니어 좌우 발소리 = 이름표에 없는 번호 둘). 이름 없는 번호를 횟수순으로 뽑아 상위 몇 개를 앞뒤 소리로 가린다. 횟수가 비슷한 둘이 번갈아 오면 좌우 발이다.
- 조작 중인 캐릭터만 내는 소리를 찾아 `player` 로 둔다(니어 `pl####_mov_start`·`dash_end` — NPC 는 `wait_npc_lp`). 동료 소리가 나한테 오던 원인이었다(11-09).
- 기록을 얻자고 사용자에게 플레이를 시키지 않는다. 훅을 붙여 두면 다음 판에 쌓인다.
